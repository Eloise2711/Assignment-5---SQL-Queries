3. Which volunteer(s) are working on transporting tasks? Query should retrieve names rather than
ids.

SELECT DISTINCT volunteer.volunteerName
FROM volunteer
JOIN assignment ON volunteer.volunteerId = assignment.volunteerId
JOIN task ON assignment.taskCode = task.taskCode
JOIN task_type ON task.taskTypeId = task_type.taskTypeId
WHERE task_type.taskTypeName = 'transporting';

│ volunteerName │
╞═══════════════╡
│ George Brewer │
╰───────────────╯

Explanation: This query joins the volunteer, assignment, task, and task_type tables to find distinct 
names of volunteers who have been assigned to tasks classified under the 'transporting' task type.

11. How many volunteers are assigned to tasks with each different status? The answer should show
each different status and the number of volunteers sorted from highest to lowest.

SELECT task_status.taskStatusName AS status,
COUNT(DISTINCT assignment.volunteerId) AS numVolunteers
FROM task_status 
JOIN task ON task.taskStatusId = task_status.taskStatusId
JOIN assignment ON assignment.taskCode = task.taskCode
GROUP BY task_status.taskStatusName
ORDER BY numVolunteers DESC;

╭─────────┬───────────────╮
│ status  │ numVolunteers │
╞═════════╪═══════════════╡
│ open    │             4 │
│ closed  │             3 │
│ ongoing │             2 │
│ pending │             1 │
╰─────────┴───────────────╯

Explanation: This query joins task_status, task and assignment tables, groups the rows by task status, counts the 
number of distinct volunteers assigned to tasks under each status, and sorts the results in descending order by count.

12. Which task creates the heaviest set of packages and what is the weight? Show both the
taskCode and the weight (You should be able to do this without using any sub-queries).

SELECT taskCode, SUM(packageWeight) AS totalWeight
FROM package
GROUP BY taskCode
ORDER BY packageWeight DESC
LIMIT 1;

╰──────────┴─────────────╯

Explanation: This query calculates teh total weight of packages for each task by grouping by taskCode, summing packageWeight, 
and ordering the sums from largest to smallest to return top result without sub-queries.

14. Of those items that have been packed, which item (or items) were touched by fewer than 3
volunteers? Answer should be item descriptions.

SELECT item.itemDescription
FROM item
JOIN package_contents ON package_contents.itemId = item.itemId
JOIN package ON package_contents.packageId = package.packageId
LEFT JOIN assignment ON package.taskCode = assignment.taskCode
GROUP BY item.itemId, itemDescription
HAVING COUNT(DISTINCT assignment.volunteerId) < 3;

│ dried fruit     │
│ men's coat      │
│ sleeping bag    │
│ tent            │
│ women's coat    │
╰─────────────────╯

Explanation: This query joins packed item through package_contents, package, and assignment to 
volunteer, groups by item, and filters using HAVING to find items associted with fewer than three 
distinct volunteers.

15. Which packages have a total value of more than 100? Show the packageIds and their value
sorted from lowest to highest.

SELECT package_contents.packageId,
SUM(item.itemValue * package_contents.itemQuantity) AS totalValue
FROM package_contents
JOIN item ON package_contents.itemId = item.itemId
GROUP BY package_contents.packageId
HAVING totalValue > 100 
ORDER BY totalValue ASC;

╭───────────┬────────────╮
│ packageId │ totalValue │
╞═══════════╪════════════╡
│         6 │      150.0 │
│         2 │      151.0 │
│         4 │      350.0 │
│        10 │      750.0 │
│         5 │     1420.0 │
╰───────────┴────────────╯

Explanation: This query joins package_contents and item to compute total value of each package 
(multiplying quantity by item value and summing per package), filtering for packages with a value 
over 100, sorted from lowest to highest.
